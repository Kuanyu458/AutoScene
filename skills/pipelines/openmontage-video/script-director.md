# Script Director — openmontage-video

Write a concise outcome-led script whose visible actions can be recorded or
provided. Each feature gets a named scene: one semantic result, one optional
beat marker, and a readable hold. Mark semantic-locked moments explicitly so
audio timing cannot move them. Do not claim a browser flow, model, or source
document that the job does not provide.

Keep captions short enough for 30 fps 1920x1080 output and preserve a clear
opening problem, proof, benefit, and call to action. Checkpoint the script
before scene planning.
